# Repository Security Statement

## Intended Users

This repository is intended for myself, my professor, and authorized course staff to access and review code submitted for class assignments.

## Security Risk Assessment

The security risk associated with this repository is relatively low because it contains coursework and educational code rather than sensitive personal information or production applications. However, unauthorized changes to the code could affect the accuracy and integrity of my assignments. Additionally, any accidentally uploaded passwords, API keys, or personal information could create security risks.

## Security Measures

I avoid including passwords, API keys, and other sensitive information in this repository. I also review my code and files before committing changes. Since this repository is primarily used for individual coursework, additional security measures such as a CODEOWNERS file or pull request rulesets are not currently necessary. I will reassess these measures if the repository is used for collaborative development or begins containing sensitive information, as the course continues.
